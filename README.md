#### Introduction-to-vibe-coding
- Welcome to the course Introduction to vibe coding! This course teaches you how to build software using vibe coding - a modern development workflow where you collaborate with AI models to generate, refine, and deploy code. You’ll learn the fundamentals of prompting, context management, and agent-assisted coding using tools like ChatGPT, Gemini, and the Cursor IDE (*). Through hands-on practice, you’ll build a small working application, improve it iteratively with AI, and deploy it locally and to the cloud. After completing the course, you’ll know how to work efficiently and creatively with AI-assisted development tools while also keeping the security and ethical aspects in mind.
